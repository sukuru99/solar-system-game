# بازی منظومه شمسی 🪐

یک بازی آموزشی تعاملی برای یادگیری ترتیب سیارات منظومه شمسی. در این بازی، دانش‌آموز باید هر سیاره را بکشد و در مدار درست خود به دور خورشید قرار دهد.

## ویژگی‌های بازی

- 🪐 قرار دادن سیارات در مدار درست
- 🖱️ قابلیت کشیدن و رها کردن سیارات
- ✅ نمایش بازخورد برای پاسخ درست
- ❌ نمایش بازخورد برای پاسخ نادرست
- 📚 نمایش اطلاعات آموزشی درباره هر سیاره
- 📱 طراحی واکنش‌گرا برای موبایل و دسکتاپ

## فناوری‌های استفاده‌شده

- HTML
- CSS
- JavaScript
- JSON

## هدف پروژه

آموزش ترتیب سیارات منظومه شمسی به روشی تعاملی و سرگرم‌کننده.
